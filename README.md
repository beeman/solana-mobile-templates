# solana-mobile-templates

Templates used by the [repokit](https://github.com/beeman/repokit) CLI.

## Usage

Run the `create-solana-dapp` command with the `-t gh:beeman/solana-mobile-templates` option and use the interactive prompts to
create a new template repository.

```sh
# npm
npm create solana-dapp@latest -t gh:beeman/solana-mobile-templates

# pnpm
pnpm create solana-dapp@latest -t gh:beeman/solana-mobile-templates

# yarn
yarn create-solana-dapp -t gh:beeman/solana-mobile-templates
```
